# Hold expiry

**Status**: Current policy

Holds expire 48 hours after the pickup notification. The pickup window returns uncollected items to circulation for the next reader.

Source: [Desk Policy, Pickup window](../workspace/Sources/Desk%20Policy.md#pickup-window). In the copied workspace, a note saved under Decisions would use the relative path ../Sources/Desk%20Policy.md#pickup-window.
